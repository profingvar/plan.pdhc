What this builds

A concept is based on a term that is either local or taken from a canonical vocabulary (SNOMED CT, LOINC, ATC and the others). The concept has a value that is either continuous — a measurement on a scale, with a unit and a range — or categorical, meaning separate alternative responses. Those alternatives are collected in a value set.

A PlanDefinition is a standard plan for the execution of transactions, each of which is based on a concept.

Termlocal or canonical → Conceptcontinuous or categorical → Value setthe alternatives, if categorical → Transactionone concept, asked once → PlanDefinitionthe standard plan

A concept with no reference into a canonical vocabulary is local — that is the assumption, not an omission to be filled in later, and the authoring forms default to it.
